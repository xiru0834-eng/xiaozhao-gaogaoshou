# 校招高高手 × 拾知面试陪练

[English](README.md) | 中文

## 概述

首页整合校招高高手的公司清单、投递记录和拾知面试陪练。筛选公司、记录投递进度，再点 **准备面试**，为你确认的目标岗位练习。内置智能体应用开发、计算机网络、数据库、Java、Redis 五个方向的 56 道原创问题，支持口述或文字作答、查看反馈和重新回答。数据保存在本机 SQLite，AI 点评使用 Harness 中配置的模型。

首页展示最近练习、今日复习题数和下一场面试日程。回答默认进入专注视图，可展开导航。回答草稿以练习和题目为单位保存到 `drafts.sqlite`，500 毫秒防抖写入；刷新或重新打开练习可恢复。界面明确显示保存状态，失败可重试；多窗口修改通过版本检查阻止覆盖，提交后旧草稿自动失效。浏览器本地存储只用于请求中断时的临时恢复。

右上角设置集中提供模型与语音、外观、数据与备份及高级选项。桌面版支持配置密钥和加密完整备份；网页部署仍在高级设置中管理模型，通过 `.env` 配置语音，并停服备份 `DSH_HOME`。详见[桌面版说明](../shizhi-desktop/README.zh.md)。

## 使用本产品

### 启动本地产品

Windows x64 用户也可以使用[桌面版安装包](../shizhi-desktop/README.zh.md)，无需安装开发工具。桌面版提供独立窗口和首次密钥配置，使用单独的数据目录。以下步骤用于源码网页版。

使用 Node 24.14 或更新的 24.x 版本，并确保 Git、npm、pnpm 可用。本产品在校招高高手仓库内运行，直接使用根目录的 `src/` 和 `web/`。构建检查工作台入口、身份占位符、必要页面元素及两个适配器；兼容这些接口的界面和目录更新可以直接构建。[career-upstream.json](scripts/career-upstream.json) 保留首次整合的来源版本，不限制日常修改。

```powershell
git clone https://github.com/xiru0834-eng/xiaozhao-gaogaoshou.git
cd xiaozhao-gaogaoshou
npm ci
npm run coach:install
npm start
```

已有源码目录时更新 main，跳过克隆。打开 Harness 输出的本地私有链接。产品采用顶部品牌栏和全宽内容区，不显示框架左侧栏。启动跳过面向框架开发者的内测声明，保留可稍后配置的模型引导和设置入口。顶部切换 **校招工作台**、**面试陪练** 和 **直接聊聊**，无需选择工作区。**历史会话** 按需打开原有聊天和练习，底部保留插件管理入口；聊天或插件页面的 **返回工作台** 会创建新的空白会话，不删除历史记录。每次开始练习会创建独立会话，复盘可从 **面试陪练 → 练习记录** 查看。浏览公司、记录投递与保存回答无需模型密钥；聊天与 AI 点评需要在右上角 **设置 → 模型** 中配置密钥。按 Ctrl+C 停止服务。

启动脚本构建前端，首次运行时将此目录作为链接 bundle 安装进隔离的 `web` profile，再通过正式的 `dsh web` 入口启动，默认地址为 `127.0.0.1:4317`。`SHIZHI_PORT` 可修改端口，`DSH_HOME` 可覆盖默认的产品内 `.dsh-home` 目录。复用已有 profile 且 pnpm 提示存储位置不一致时，将 `SHIZHI_PNPM_STORE` 设为该 profile 原用的存储目录后重启。请勿公开包含令牌的启动链接。

### 练习与复盘

在公司卡片点 **准备面试**，填写目标岗位，再选择练习方向。点评使用已确认的岗位背景；回到这家公司可以查看关联练习和已保存的分数。题目是通用知识练习，不是经核实的公司真题。练习不会改变投递状态。315 家公司来自上游历史快照，截止时间、岗位和推荐码请在招聘官网核实。整合版使用独立的投递数据库，不自动导入朋友已有的个人记录。

提交时先保存回答，再请求模型点评。点评、后续问题和模拟面试复盘都留在练习页面，重新打开会话也会恢复此页面。从练习进入 **直接聊聊** 时会新建独立聊天。卡片区分正在运行和结果未完成，并提供重试；重试复用已保存的点评。新点评按答对、不完整、有误、遗漏和需确认逐项展示，引用回答原话说明依据，给出下一次最值得改进的一点。固定题目必须覆盖参考要点，存储层拒绝回答中不存在的引用；这不保证模型判断正确。展开 **参考答案** 可查看模型生成的讲解。**重新回答** 新增作答，前后对比展示最近两次已点评回答及补上的知识点。**针对回答追问一题** 围绕已有回答追问，**结束并保存** 无需模型即可归档。Markdown 导出保留逐项点评、岗位与项目资料。

陪练顶部提供 **练习首页**，以及 **题库练习、模拟面试、岗位专项、复习计划、练习记录、已斩题** 六个功能页面。当前页面的入口用主题强调色突出，鼠标悬停时也保持选中状态。题库支持关键词搜索和方向筛选，**练习记录** 可打开进行中的练习或已结束的复盘。在这些页面间切换会保留当前回答草稿，并将目标页面标题和选中导航带入视野。

陪练默认采用浅色工作台界面，搭配白色内容表面、墨蓝正文和蓝绿控件。练习首页展示已保存题库的数量，点击方向直接打开对应筛选，并提供模拟面试、岗位专项与复习计划入口。已有练习直接恢复到当前题目。首页使用真实界面内容，不依赖摄影素材。模拟面试设置使用支持键盘操作的单选组和原生下拉框。准备表单未填完整时，页面提示并聚焦第一个缺失字段。反馈先展示下一次改进建议，再展示逐项点评。控件支持可见焦点、禁用状态和减少动画设置。校招与陪练共用横向功能导航、内容宽度、字体、卡片和表单控件。内嵌校招页以小型角色点缀替代大幅场景与重复品牌。**设置 → 通用设置 → 外观** 统一控制校招、陪练、顶部栏和设置的浅色、深色或跟随系统，刷新后仍然生效。校招明暗按钮和衣橱中确认的明暗选项也会更新这一全局偏好；**换肤** 保留配色与角色选择，未确认的预览不会改变工作台。导出备份菜单显示在角色按钮和统计卡片上方，四个导出选项在窄窗口中保持可见、可点击。独立运行的校招应用保留自己的布局。

导航、题目分类和单选组都用共用强调色表示当前选中项，悬停时保持选中状态；默认浅色皮肤使用深蓝绿。两边的功能导航支持横向滚动，并将当前页面保持在视野内。布局按面板的实际可用宽度调整：准备表单和回答对比在窄面板中纵向排列，复习条目为长题目保留足够宽度。文本框采用浅色内嵌表面，并显示清晰的聚焦轮廓。

复习计划中的 **今天复习什么** 按相同主题与题目合并历史记录，展示反复遗漏的知识点。建议间隔为薄弱题 1 天、其他题 7 天，可提前重练；这是固定规则，不是经过验证的个性化记忆算法。需确认的点评单独标识，不自动判定为掌握或答错；旧记录暂按分数筛选。**重新练这题** 新建练习并关联来源，保留原档案，支持与来源回答对比。

进入 **岗位专项**，填写岗位及岗位要求或项目经历，即可生成专项题并继续追问。进入 **模拟面试** 后由 AI 根据回答连续提问，不提供手动选题。模拟面试还需项目经历，可选择 10/15/20 分钟、最多 4/6/8 题、难度与面试官风格。默认 15 分钟、6 题，不含编程题；计时包括模型等待时间。回答后继续提问，达到题数或时间上限后生成统一复盘，也可提前结束。到时仍能提交当前回答；未提交文字需提交或清空后再结束或切换练习。复盘依据已保存问答，区分已体现能力、证据不足和未考察内容。失败可重试，或仅保存问答；进行中不展示评分和参考答案。

智能体应用开发题库包含 24 道原创口述题，按 Agent 基础、工具与 MCP、RAG、上下文与安全、工作流可靠性、评测与项目表达分为六组，面向校招与初级应用开发。在 **题库练习** 中可从任意待练题开始；普通练习中的 **本方向选题** 可切换同方向问题并保留已有回答，**下一题** 跳过本次已练和已斩题目。点评复用每题固定参考要点，并可打开官方参考资料；题目不是公司真题，参考要点也不是唯一措辞的标准答案。内容维护入口为 [智能体题库](src/domain/agent-catalog.js)。

点击 **斩题 · 我已掌握**，会将题目从待练题库和复习队列移入 **已斩题**。这是你对掌握程度的主动标记，与模型评分独立；历史回答和当前草稿仍保留，点击 **恢复到待练** 可重新加入题库。**面试沉淀** 分类收录历史陪练生成的问题。斩题状态按规范化题目文字保存在本机，并保留题目快照，删除来源练习后仍可恢复；这不会阻止 AI 面试生成相似问题。

融合工作台包含岗位采集、每日更新、邮件核对、求职任务、面试日历和角色主题。**采集与邮件模型** 单独配置这些工作台服务；面试与聊天继续使用 Harness 模型设置，已有密钥保持原位置。每日更新需主动开启，邮箱需用户自行授权账号。原生桌宠保留独立可选启动入口。

### 语音输入

未配置独立服务时，浏览器支持即可使用自带语音识别。它可能将音频发送给浏览器厂商，依赖浏览器支持、麦克风权限与网络连接。配置独立服务后，浏览器负责录音，停止后由服务端转写。提交前请检查可编辑的文字。题目朗读使用浏览器语音合成与可用的系统音色。

口述界面区分麦克风授权、录音计时、接收最后一句和转写状态，期间暂停提交、换题和朗读。点击 **取消本次口述** 会恢复录音前的文字，迟到的转写不会覆盖草稿。浏览器识别报错时保留原草稿和已确认的句子；语音配置读取失败时可重试连接，不自动改用其他语音服务。结束口述后仍需手动确认并提交；超过 16000 字的文字保留供编辑，整理到限制内才能提交。

接入阿里云百炼时，将本产品目录的 `.env.example` 复制为 `.env`，填写北京地域的 API Key。模板已配置以下 [Qwen-ASR 同步接口](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)，也支持将 URL 换为你在百炼控制台获得的北京业务空间专属域名。免费额度和调用权限以你的百炼账号为准。

```dotenv
SHIZHI_ASR_PROVIDER=qwen
SHIZHI_ASR_URL=https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
SHIZHI_ASR_MODEL=qwen3-asr-flash
SHIZHI_ASR_API_KEY=
```

修改 `.env` 后重启产品并刷新网页。千问密钥为空时暂停口述并提示补充配置，文字作答仍可使用；鉴权或权限失败时显示对应提示。密钥只留在服务端，录音以内存中的 Base64 音频发送给千问，不保存音频文件，也不需要公开音频下载链接。千问录音支持 WebM 或 Ogg；默认限制为 180 秒、8 MiB，转写请求超时为 60 秒。插件的 `speech` 配置可覆盖 `provider`、`url`、`model`、`apiKeyEnv`、`maxSeconds`、`maxBytes`、`timeoutMs`；千问上限为 300 秒、10 MB。页面会在录音前显示服务地址，转写结果需手动确认后提交。

使用 [Speaches 转写](https://speaches.ai/usage/speech-to-text/)或其他 multipart 转写服务时，将 `SHIZHI_ASR_PROVIDER` 设为 `multipart`，将 URL 设为完整转写接口（例如 `http://127.0.0.1:8000/v1/audio/transcriptions`），并填写该服务已安装或可调用的模型 ID。`multipart` 为未指定 provider 时的默认值，兼容已有配置；本地服务未启用鉴权时密钥可留空。清空 URL 和模型可恢复浏览器识别。

### 数据与检查

本节路径相对于 `products/shizhi-interview`。练习数据默认位于 `.dsh-home/profiles/web/data/shizhi-interview/interview.sqlite`，旁边的 `career/` 目录保存 `catalog.db`、`qiuzhao.db`、`schedules.db`、`mail.db`、`runtime.db` 及原有的 `profile-id`。共享工作台保留已有资料身份并加入进程锁，启动时备份公司、投递和日程存储。工作台导出菜单可分别下载公司目录和投递进度备份；完整保留产品数据目录才能保留公司关联练习。Harness 对话数据在同一个隔离 home 内。Git 忽略密钥、构建产物、依赖和本地数据。已有拾知用户可先停止旧服务，再将 `DSH_HOME` 指向原来的数据目录后启动本分支；不要同时让两个服务使用同一个数据目录。

面试练习数据库升级到 SQLite `user_version=2`，新增题目掌握状态存储，保留既有的可空结构化点评字段和练习记录；升级前请备份数据目录。旧记录不会自动补写点评，重练后才有逐项反馈。

```powershell
cd products/shizhi-interview
npm run verify
```

该命令构建两套前端和复用的上游存储模块，运行领域、存储、陪练及语音回归测试，并检查 JavaScript 语法。整合测试覆盖稳定公司标识、SQLite 重开后进度、可用备份、公司关联点评上下文、路由鉴权和进行中请求的清理。测试覆盖自由选题、斩题与恢复、历史回答保留、数据库升级及各功能页面布局。自动测试还回放虚构回答在真实页面取得的模型结果，覆盖点评证据、重答对比和模拟面试复盘；样例保存在 `test/fixtures/recorded-coach-results.json`，不需要密钥，也不是权威答案。自动测试不衡量模型点评质量或实体麦克风识别效果。

## 实现方式

<summary>展开实现细节</summary>

[Markdown 容器](src/client/shared/ui.js)将反馈、历史回答和讲解的样式限制在所属界面内。时间轴卡片使用[产品样式](src/client/shared/styles.js)；练习工作台使用独立的[陪练样式](src/client/shared/coach-styles.js)，覆盖正文、链接及行内代码配色。

<a id="model-experience"></a>

## 模型体验

点评请求明确指定已有题目和作答，要求模型读取存档并避免重复创建回答。每次新请求附带已记录的范围提示：普通问候和知识问答不恢复历史点评，只有明确的练习请求进入练习流程。模型按当前请求回答，不向普通用户列出内部工具与记录编号。内置题目附带参考要点。分数是模型给出的练习反馈，不代表录用概率。固定题目的选择与归档无需推理；追问、讲解和个性化评价需要可用的模型。

<a id="known-limitations-and-deferred-work"></a>

## 已知限制与后续工作

这是中文桌面浏览器首版，尚无订阅、支付、账号或生产托管。原生 Python 桌宠是独立可选桌面入口；本次整合不代表真实邮箱、关闭后台后的自动唤起或广泛招聘来源均已验收。浏览器识别不保证离线；本地转写服务需要单独安装。点评可靠性仍需真实用户评估。参考讲解按题目存储，评价按每次回答存储。本 bundle 与原版 `dsh-interview` 共享工具和路由名，不能同时启用。
