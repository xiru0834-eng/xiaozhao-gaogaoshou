# 小窗位置书签与浏览恢复

## 使用与范围

- 点击公司行右侧的书签图标“标记这里”，保存一个手动位置书签；再次标记别的公司会替换它。
- 筛选摘要行出现“回到 · 公司名”。点击恢复搜索、公司性质、进度筛选、列表位置，并选中该公司。旁边的 × 只清除书签。
- 自动浏览记录与手动书签独立。滚动或切换公司后，停止操作约 200ms 保存浏览位置；重开小窗后恢复。
- 不修改公司目录、公司排列、投递状态、每日投递计数或 qiuzhao.db。
- 沿用薄荷石墨配色与原有密度，不增加独立工具栏；按钮可用键盘操作，有可见焦点和文字标签。

## 保存契约

原生桥新增 `load_navigation()` 和 `save_navigation(kind, point)`，只访问当前应用数据目录的 `companion-navigation-preferences.json`。没有新增 HTTP 接口。该文件由现有 `*preferences*.json` 忽略规则排除，不进入 Git。

`kind` 仅允许 `bookmark`、`browse`。`point` 为 null（清除）或固定字段对象：

| 字段 | 含义 |
| --- | --- |
| name | 选中公司；手动书签为被标记公司 |
| anchor / offset | 首个可见公司的名字、其被滚出顶部的像素量 |
| scroll | 找不到锚点时的滚动位置回退值 |
| query / owner / stage / tab | 搜索与筛选条件 |
| onlyCode / recent | 内推码、最近新增筛选 |

文字最多 500 字符，坐标有限且非负，枚举及布尔值按类型校验；文件大小限制 20KB。RLock 串行读改写，临时文件后原子替换，两个字段互不覆盖。前端串行发送写入，手动书签等确认后才显示“已标记”。没有传入路径或任意文件访问能力。

## 边界行为

- 公司状态变化导致旧筛选排除它：手动返回时放宽筛选，并明确提示；不篡改投递状态。
- 公司已移除：提示“不在当前台账”，保留当前浏览上下文，不静默换成别家公司。
- 自动恢复只在首次收到目录时执行，5 秒轮询不反复跳回旧位置。
- 保存失败不更新手动书签，提示重试。损坏的偏好文件保留、不自动覆盖；其他台账功能仍可用。
- 从菜单退出/主动收起前等待浏览位置写入；进程被强制结束或断电可能丢失最后 200ms 内尚未保存的位置。
- 小窗采用 WebView2 NavigateToString，不能依赖 about:blank 页面的 localStorage；正式持久化走原生文件。浏览器隔离预览仅以 localStorage 模拟桥。
