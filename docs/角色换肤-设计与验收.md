# 角色换肤 · 设计与验收

## 范围与设计

为 TypeScript 工作台增加独立外观系统，保留“薄荷石墨”原版，新增霁蓝、绯樱、紫夜、琥珀四套主题。以原版绿色 Q 版小助手为画风参考，但不是换色：霁蓝是姬发长直发/抱书/三无；绯樱是红棕侧马尾/短外套/傲娇；紫夜是银紫侧辫/针织衫/慵懒；琥珀是双丸子头/卫衣/元气。发型轮廓、服饰、表情、动作各自独立。所有角色可爱、非性化。角色、强调色、底色、侧栏协调联动；浅色/深色独立选择。

用户连续反馈后的约束：弃用第一轮成熟半写实立绘；也弃用第二轮与绿色角色刘海、构图过近的换色变体。最终仅使用一幅同画师感的四人格设定图，CSS 精确显示四个不同象限；不拼接不重绘原图，原版绿色角色保持不变。

遵循 Impeccable 的产品界面规范：插画集中在换肤预览和侧栏独立区域，不放在文字后面、不覆盖列表、不增加主列表高度。截止、错误、面试和成功状态保留语义色及文字，不因换肤变成装饰色。

交互：顶部“换肤”打开主题衣橱，选择后先预览，再点击应用；取消或 Escape 不改外观。支持隐藏角色、恢复薄荷、保留原有明暗快捷开关。外观只存当前浏览器，不写 SQLite、不改投递数据、API 密钥或模型配置。存储不可用时仍能本次使用并明确提示。窄屏自动隐藏侧栏大图。

## 不在本轮

- 不改 18763 旧版桌面应用、原生贴边助手、桌面图标或后台逻辑。
- 不接云端皮肤商店、上传自定义图片、跨设备同步。
- 不改变自动搜岗计划与其已有文档。

## 验收门槛

1. 五套主题可切换，四幅原创插画打包本地，断网可读，不依赖外站图片。
2. 浅/深模式独立；刷新后恢复选项；坏值、未知主题、浏览器存储禁用安全回退。
3. 主正文、次要文本、强调按钮和选中态对比度 ≥ 4.5:1；语义状态不被皮肤覆盖。
4. 键盘可打开、选择、应用、Escape 取消，焦点返回发起按钮。
5. 320/768/1024/1440 宽度检查；不遮挡主列表或造成新横向溢出。
6. 保留搜索、筛选、折叠、紧凑视图、模型设置与岗位更新入口；公司数/个人状态不变。
7. 新增单测先红后绿；完整 TypeScript 测试与构建通过；浏览器截图/实际交互验收。

## 交付和边界

在 TypeScript 预览顶部点击“换肤”进入主题衣橱。绿色原版仍是默认外观；测试结束恢复原版，只保留蓝色的未应用预览供查看。本轮不更新旧版 18763 / 原生贴边小窗的换肤能力，不声称已打包桌面安装版。

素材提示词和复用规则见《角色素材-生成说明.md》。只用本地打包素材，不增加依赖或远程图床。按代码审查的正确性、安全性、可维护性与性能项核验：外观模块独立，持久化值经白名单处理，主题不进入数据库，语义状态色不随装饰主题改写。
