# 本地功能集成到 main 的验收记录

## 范围

合并当前 TypeScript 工作台分支及其本地实现：邮件与求职任务、日历、受限每日更新、五角色外观和 Windows 桌宠。同意公开发布的仅是脱敏程序与公共素材，不包含个人数据库、密钥、授权缓存、简历或运行截图。

保留 main 已有的首页、海报和使用指南；不替换安装目录、重启正在使用的服务或迁移个人资料。公开源码更新不等于桌面安装快照自动升级。

## 本轮检查与修正

- 首轮 TypeScript 单元/接口/异常测试 252 项通过，Python 兼容与桌面回归 92 项通过；类型检查和生产构建通过。
- 生产及开发依赖审计使用官方 npm registry，0 已知漏洞；默认镜像未实现审计接口，不能把其 404 当作审计通过。
- 公开前新增忽略规则回归：截图、QA 产物、桌面配置、迁移回执及邮件设置原来未全部被忽略，先复现失败，再补规则后通过。
- 移除脚本对维护者绝对路径的依赖；文档路径改用用户目录占位，移除具体个人投递状态与数据库指纹。
