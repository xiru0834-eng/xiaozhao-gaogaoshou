# 悬浮助手 · 搭档口袋

## 范围与方向

只改桌面贴边助手的呈现和交互，不改完整工作台、数据库、投递状态接口、自动隐藏计时、原生窗口定位及后台任务。现有仓库其他未提交修改不处理。

使用 Impeccable 的 product / delight 规范：角色承载个性，内容与动作承载效率。使用已有五角色原画，不重新生成或替换角色。

参考：
- [Raycast 紧凑搜索](https://manual.raycast.com/search-bar)：把搜索和高频动作放在短路径上。
- [Windows Widget 设计](https://learn.microsoft.com/en-us/windows/apps/design/widgets/widgets-design-fundamentals)：小尺寸聚焦、渐进展示、明暗可读。

场景：用户在普通室内光线下浏览招聘网页，侧边小窗用于快速查公司、复制推荐码和标记进度。保留亮/暗模式，默认跟随现有个人设置。

## 设计

- 小窗上方为角色签名区：头像、角色名、性格短句和固定/收起/设置；非巨型宣传横幅。
- 收起保持现有 28×88 原生尺寸，做成带角色头像的书签；贴左/右方向匹配，不改变原生自动收起规则。
- 五个性格主题：薄荷温柔、霁蓝安静、绯樱傲娇、紫夜慵懒、琥珀元气；切换仅保存外观偏好，不更改投递数据。
- 公司状态标签和搜索始终可见，低频筛选独立展开；底部详情默认折叠，投递入口常驻。
- 380×680 默认紧凑布局至少完整显示七家公司；320×560 无横向溢出，展开详情后列表仍可滚动。
- 重要反馈（未连接、未保存、重试）明确保留，不用角色台词掩盖错误。

## 验收

- 既有 12 个小窗单测通过；新增外观默认值、五角色切换、异常偏好回退、贴边方向测试。
- 独立浏览器预览使用模拟进度，不连接或写入真实数据库。
- 亮/暗、五主题、小窗口、筛选、空结果、详情、复制、保存失败重试、书签、收起展开、减少动态效果检查。
- 检查正文/说明对比度，保存截图；测试记录追加在文末。
- 部署前备份原 companion.html / companion.py，检查文件未被其他工作修改；不重启台账后端。
