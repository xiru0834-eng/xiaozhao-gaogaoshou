# 模型设置：需求、可行性、实现与验收

日期：2026-09-20。用户确认：自定义 OpenAI 兼容接口；本轮做保存、连接测试、实际生成，不接自动搜岗。

## 1. 目标与可行性

在 TypeScript 工作台新增模型设置，形成「填写 → 保存 → 测试实际生成 → 试用」闭环。使用现有 Node 24 本地服务，浏览器只请求本机；后端访问用户明确配置的 HTTPS Chat Completions 服务。无需另起微服务或引入模型 SDK。

第一版只支持非流式文本 `POST {baseUrl}/chat/completions`，Bearer API Key；支持 `max_tokens` / `max_completion_tokens` 选择。不声称兼容 Responses、Anthropic、厂商专用协议或所有推理模型。模型列表不是必需接口，模型 ID 手工填写。端点自动预览，完整 chat/completions 地址可规范化，避免重复拼接。

Windows 通过 DPAPI CurrentUser 加密密钥，配置与密文作为一个原子文件保存在独立资料目录；其他系统拒绝持久化密钥，不退化成明文。DPAPI 保护静态文件，不防同一 Windows 账户下的恶意进程；换机器/账户需重新输入密钥。

T07/T08 的模型子集可独立于 T06 原生助手桥接实现；本轮不将 T06、求职偏好、定时采集、联网搜索或自动入库标为完成。旧 Python 18763 入口保持原样；本功能在 TS 18765 工作台提供。

## 2. 功能需求

| ID | 需求 | 验收行为 |
|---|---|---|
| F1 | 一个活动连接：HTTPS Base URL、模型 ID、输出上限、超时、Token 字段 | 边界校验；错误不覆盖已保存配置 |
| F2 | 密钥保留、更换、清除 | 密码输入框不回显旧密钥；API 只返回 hasKey；清除后不可调用 |
| F3 | 持久化及版本冲突 | 重开可用；旧版本保存拒绝；地址改变必须重新输入/清除密钥，不能把原密钥转发到新地址 |
| F4 | 明确分离保存和测试 | 保存不会联网；改变配置使旧成功状态失效；加载时不自动调用 |
| F5 | 连接测试是真实短消息生成 | 收到合法且非空的 assistant 文本才成功；HTTP 200 或模型列表可读不等于成功 |
| F6 | 输入一句话实际试用 | 只发送用户输入，不附带简历、公司表或投递记录；文本输出不执行 HTML/工具 |
| F7 | 可操作的错误提示 | 区分配置缺失、鉴权、地址/模型、限流、配额、超时、网络、协议、空输出、服务错误 |
| F8 | 进行中与取消 | 请求中禁止重复操作，可停止；断开取消上游；不自动重试，取消/超时不保证免计费 |

## 3. 非功能需求与威胁边界

- 安全：设置读取、保存、调用均验证本机 Host / Origin / 会话令牌 / profileId；不同资料绝不串用。密钥不进 URL、日志、响应、localStorage、Git、状态导出或 SQLite 备份。
- 网络：仅 HTTPS 公网端点；禁止用户名密码、查询串/片段、私网/本机/元数据 IP、重定向。DNS 所有结果校验且连接固定已核验 IP，防 DNS 重绑定。此轮不支持 Ollama/内网服务、系统代理或自签名证书。
- 资源：单资料最多一个模型调用；每分钟最多 6 次；请求超时 10–120 秒；用户输入最多 2,000 字符；输出 32–4,096 tokens（测试最多 64）；上游响应最多 1 MiB。无后台请求、无无限重试、无自动付费。
- 可靠性：设置原子替换；写失败保留旧配置；服务重启后设置可读；损坏配置明确报错，台账仍可用。测试成功只代表当次、该版本配置可用，不代表永久可用。
- 可用性：继承薄荷石墨视觉，设置与试用分区；清晰显示真实请求地址、费用说明、保存/测试结果；有错误、加载、空状态；键盘和窄窗口可操作。
- 兼容性：新逻辑全 TS，不改旧状态 API 和数据库；不发布、迁移真实资料、不注册计划任务。

资产是密钥、用户输入、调用额度、原投递数据。外部网页不能触发本机模型请求；服务输出是无权数据；地址变化不能复用旧密钥。日志只允许脱敏错误类别，绝不展示上游原始错误体。

## 4. 契约与模块

- `src/shared/model-contract.ts`：输入校验、配置/结果/错误类型、受控错误文案。
- `src/server/model-secrets.ts`：Windows DPAPI（固定命令，秘密只走 stdin，隐藏子进程窗口）。
- `src/server/model-settings.ts`：model-settings.json 原子持久化、密文、版本冲突、端点绑定。
- `src/server/model-client.ts`：HTTPS/DNS 安全、协议解析、输出/耗时/usage；不记录提示词。
- `src/server/model-service.ts`：单并发、限流、调用生命周期。
- `src/client/model-settings*.ts/css`：配置与试用；无秘密持久化。
- `GET /api/model-settings`：脱敏配置，需 token+profile；`POST` 同路径：expectedRevision+config+keyAction。
- `POST /api/model-tests`、`POST /api/model-generations`：expectedRevision；后者另有 prompt。返回 profileId + 结果；错误统一 code/message。一次短请求受超时限制，不引入采集任务队列。

## 5. 实施顺序和测试门槛

1. S1 契约与密钥存储：先失败测试；真实 Windows DPAPI 往返（合成密钥）、重开、保留/更换/清除、冲突、地址改变、损坏/写失败。
2. S2 模型服务：受控本机 HTTP fixture 验证真实传输/协议，不冒充真实厂商；成功、401/403/404/429/5xx、无效 JSON、空文本、超限、超时、取消；公网地址/DNS/重定向独立负向测试。
3. S3 本机 API：无 token / 外站 / 错资料均不能读配置或触发请求；未配置不影响台账；并发/频率限制；进度和公司快照前后一致。
4. S4 页面：保存、重开、替换/清除、失败提示、测试与试用、防双击、取消；桌面/窄屏/暗色实际浏览器查看。
5. S5 回归：`npm test`、`npm run build`、`python -X utf8 -m unittest -q`、依赖审计；记录真实结果，不以预期代替。
6. 真人凭据验收：用户在本机设置页输入自己的端点和 Key，主动点击测试，显示回答/耗时/模型。没有用户凭据时标记「待真实接口验收」，不能声称已连接。

测试素材仅合成；程序保护属于本机威胁模型，不是生产云端多租户认证。模型参数和代理兼容有差异，失败提示应指导核查服务商文档，不能静默降级参数后偷偷重发。

### 浏览器流程验收

在隔离端口 `18769`、临时资料目录和合成服务上手动验证，未使用真人密钥、未调用外部模型：

1. 粘贴完整 `/chat/completions` 地址后保存，规范化为 Base URL；旧密钥不回显，保存本身不触发生成。
2. 点击连接测试收到合成服务文本，展示模型/耗时/tokens；再输入一句话生成，收到对应文本。响应中的 `<script>` 保持纯文本，不执行。
3. 发送「模拟等待」后停止，按钮恢复；再次请求可用，不把取消报成成功。
4. 合成 401 显示鉴权错误；更换服务地址而保留密钥被拒绝，不覆盖原配置。
5. 清除密钥并保存后调用按钮禁用，刷新后仍无密钥；刷新没有自动调用。修正了清除后错误提示“请测试”的文案。
6. 320、390 和 1440 像素宽度检查无横向溢出；查看浅色/暗色布局。帮助导航能先恢复工作台，再打开说明；设置页不触发隐藏搜索框快捷键。
7. 本轮读取的浏览器控制台无 JS 警告/错误。浏览器检查是人工验收，不冒充自动化 E2E 套件。

### 未关闭的验收门槛与限制

**真实自定义接口验收待用户完成。** 当前未提供该服务的 Base URL、模型 ID 与 API Key，不能声称已连接用户真实模型，也没有真实公网 TLS + 厂商账号的成功生成证据。本机 fixture 通过不替代这一项。

操作：在设置页填可信 HTTPS 地址、模型 ID、Key → 保存 → 测试连接 → 查看非空实际回复；再输入一句话点击「发送并生成」。如果报错，依据分类检查服务商配置，不要把 Key 发到聊天、日志或截图中。

其他限制：一个活动连接、非流式文本；不支持内网/Ollama、代理专用链路、自签证书、Responses 或厂商专用协议。DNS 若被代理改写到保留地址会安全拒绝。没有模型自动发现、对话历史、每日预算或自动采集；每分钟 6 次仅为本机节流，不是账单金额上限。跨账户/机器需要重新输入 Key；同一 Windows 账户恶意进程不在 DPAPI 防护范围。
