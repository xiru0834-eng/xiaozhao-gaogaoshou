仅优化机会清单顶部横幅。沿用五个原始角色、现有主题令牌、角色开关、主题持久化和概览折叠。不改公司卡片、左侧导航、后端、数据库和个人投递数据。

2026-09-21 根据用户“用生图能力”要求，将本轮初版 SVG 场景升级为五张真正独立生成的横幅插画。使用内置 image_gen，各调用一次；以原角色为身份参考，第一张绿色插画为其余四张的画风参考。不是同图换色。

五张原 PNG 保存在 `web/public/assets/skins/{mint,blue,sakura,violet,amber}-hero-v2.png`，约 2.1–2.4 MB/张；仅当前主题加载，切换后使用浏览器缓存。原 mascot 和 cast 图集不覆盖。完整提示词见 [生图提示词](五角色主题横幅-生图提示词.md)。

展示采用右侧完整比例插画、左侧实底文字和柔化过渡；深色主题降低插画亮度，窄窗口将图画和文字上下排版。五个头像一键切换，关闭角色同时隐藏人物插画，收起概览释放列表空间。标题和统计保持真实，无自动播放或抢占点击的装饰。

## 验收计划

1. 五套真实插画和名称独立，随换肤一起更新；刷新仍保留原主题选择。
2. 深浅色、关闭人物、收起概览正常；键盘焦点明显；装饰不进入无障碍树。
3. 320/768/1024/1440 宽度无横向溢出或文字重叠；矮屏控制横幅高度，并保留收起概览入口。
4. 类型检查、场景自动测试、全套测试、构建和浏览器视觉检查。
