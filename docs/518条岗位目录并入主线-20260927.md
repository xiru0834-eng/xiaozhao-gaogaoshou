# 518 条岗位目录并入主线（2026-09-27）

## 目标与来源

把当前桌面应用的 518 条公司/岗位方向目录纳入 Git 主线默认数据，使其他人从 `main` 拉取后，新建本地资料库也能看到完整目录。这里的 518 是应用按公司展示的目录条目数，并非 518 个独立职位 ID。

来源为桌面应用 `desktop-primary` profile 的 `catalog.db`。同步工具以只读方式打开数据库，先验证 SQLite `integrity_check=ok`，再按 `sequence` 导出岗位数据及目录元信息；不会打开或复制 `qiuzhao.db`。

## 变更范围

- 保留原有 335 条目录记录的字段和顺序；其余 183 条只追加到每日追加区末尾。
- 包含完整 518 条目录、888 条别名记录、210 个新增日期，以及公司性质、招聘渠道和核验说明。
- `qiuzhao.db` 中的个人投递状态、备份和运行时 profile 均不进入 Git。
- 旧版 `products/legacy-desktop/index.html` 不属于当前 `desktop-primary` 数据源，本次不改动。

## 可重复同步

从新版本桌面 profile 的目录库追加后续新公司时，可运行：

```powershell
D:\node.exe --experimental-strip-types scripts/sync-catalog-seed.ts "<profile目录>\catalog.db"
```

工具要求数据库顺序以代码中的目录为前缀；发现缺行、顺序冲突或完整性错误会停止，不会写数据库。新公司进入 `src/shared/catalog-additions.ts` 末尾；元信息写入 `src/shared/catalog-metadata.ts`。

## 验证

- `tests/catalog.test.ts` 固定校验总数、去重、原 335 条字段/顺序哈希、历史新增日期和新追加区末尾。
- `tests/catalog-store.test.ts` 校验新建目录库包含 518 条、210 个新增日期、370 个非规范别名及性质分布。
