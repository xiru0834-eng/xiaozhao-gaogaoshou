## 这套视觉怎么继续用

- 色彩：薄荷 `#96E5C4`、石墨 `#18252B`、暖白 `#F5F4EC`，以明亮、夜间、柔和三个场景形成系列。
- 角色：沿用仓库现有吉祥物的薄荷短发、琥珀眼睛、奶油色星形发夹与深绿衣装，不使用其他游戏角色或品牌标识。
- 构图：大标题先讲一个利益点，抽象产品装置解释场景，少量文字补充功能；宣传不靠真实用户数据或成功数字。
- 生成：内置图片生成工具；唯一参考图为 [`assets/qiuzhao-mascot.png`](../../assets/qiuzhao-mascot.png)。没有上传简历、应用截图、公司目录、数据库、聊天记录或密钥作为图像参考。
- 文件：[完整提示词](prompts.md)，后续衍生请另存新版本，不覆盖这组原图。

这组图片是 AI 生成的品牌创意，不是实际 UI 截图、投递回执或功能验收证明。自动搜岗、自动投递、保证 Offer 均不在海报宣传范围内。分享时仍需遵守仓库的邀请与使用约定。
