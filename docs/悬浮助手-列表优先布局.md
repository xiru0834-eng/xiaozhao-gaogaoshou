# 悬浮助手：列表优先布局

2026-09-20。用户反馈：同时能看到的公司太少，顶部与底部占位，详情遮住列表。

## 范围与设计

当前截图对应 `companion.html` 的旧版原生悬浮助手，不是 TS 完整工作台。此轮只修改这一兼容视图及测试，不更改 Python 桥接、窗口定位、数据接口、TS 数据基础或投递记录。分享仓库与实际安装目录的原文件 SHA-256 相同；验收后仅部署此视图，并备份旧文件。原生助手仍未迁入 TS 数据层。

沿用薄荷石墨主题、原绿发角色。使用 Impeccable product/layout 流程，把结构改成：紧凑标题 → 一行今日统计 → 搜索与可收起筛选 → 占据剩余高度的公司列表 → 可折叠公司操作区 → 保存反馈。

- 去掉大幅问候标题；今日计数保留，并可打开原明细。
- 搜索常驻；状态与筛选可整体收起，生效条件有提示，不清空已选条件。
- 默认紧凑列表，保留两行公司信息；设置中可以切换宽松密度。
- 底部默认收起，保留当前公司、打开入口、上一家/下一家。展开后查看内推码、修改状态、记为已投及来源。
- 来源详情改为操作区内滚动，不再绝对定位覆盖公司行；切换公司清除上一个公司的展开来源，但不强行展开整个面板。
- 展开偏好本地记忆；折叠时焦点回到折叠按钮。Escape 优先关闭当前局部面板，未保存状态继续沿用原防退出逻辑。
- 实际窗口为 380×680 CSS 像素，另测 320×560、560×988 及宽屏。小窗口详情高度设上限，列表保留最低空间。

## 验收目标

1. 380×680 默认模式至少完整显示 6 家；收起筛选至少 7 家。记录旧版及新版实际测量，不把预估当结果。
2. 默认、展开操作、展开来源、筛选面板、空结果下，页面无水平溢出；底部操作和保存反馈可达，无详情覆盖列表。
3. 折叠与密度切换不写投递状态，不清空搜索/筛选；偏好重开保留。
4. 搜索、组合筛选、下一家、复制、标记/撤销、失败重试、设置、明暗主题可用；公开内推来源提示仍保留。
5. 真浏览器截图、布局读数、键盘操作与控制台检查；自动测试执行实际视图脚本，不只检查字符串。
6. 新 TS 测试、旧版回归与严格构建通过；真实数据库及后端文件前后摘要不变。不会为了刷新原生视图强杀可能存在未保存内容的窗口。
