# 面试形式筛选（2026-09-25）

## 目标与边界

用户只能线上参加面试。公司目录新增“面试形式”组合筛选，不改变旧公司行、投递状态或数据库。结果按 2027 届具体招聘单位、岗位、轮次解释；线上网申、线上宣讲、线上笔试、AI 测评都不能推断后续面试可线上。

## 四类状态

- 确认可全程线上：针对同一批次和适用岗位，可靠来源明确所有面试轮次可线上。
- 明确需要线下：适用流程明确要求至少一轮线下面试。
- 部分线上 / 后续待确认：仅有部分轮次线上证据，或线上、线下任选但未保证用户可选择线上。
- 面试形式待确认：无适用证据，或只有笔试 / 宣讲形式。

“线上可尝试（含待确认）”按用户偏好保留未知及部分线上公司，只排除明确要求线下的公司；它不表示获得远程面试承诺。筛“确认可全程线上”时仅返回第一类。来源 URL、核验日期、适用范围和未决问题显示在公司详情。未注明的公司默认“待确认”。官方面邀和 HR 对本人岗位的书面确认优先于公开公告；当前版本不自动读取邮件，也不代用户联系 HR。
