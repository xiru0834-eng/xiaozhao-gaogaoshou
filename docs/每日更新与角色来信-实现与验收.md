# 每日更新与角色来信：第一批实现与验收

日期：2026-09-21（悉尼）

对应：[详细设计](./每日更新与角色来信-详细设计.md)、ADR-004。

## 1. 本次交付结论

本次完成 **R1/R2 的基础工程路径**：本机设置 → 显式手动/定时触发 → 官方原生搜索适配 → 已登记来源复核 → 日报持久化 → 每日一次角色来信。并非详细设计 N01–N15 全部完成，也没有通过真实搜索质量及 Windows 唤起发布门槛。

入口：`http://127.0.0.1:18765/#daily`，顶部「每日更新」。不依赖 Codex 自动化执行；调度器属于本机 Node 后端。**后端退出、注销或关机后不会自行启动**，Windows dispatcher/系统任务尚未实现。关闭浏览器但保留后端时可继续运行。

当前真实 TypeScript 资料档案没有保存模型配置，也没有确认匹配条件，因此自动更新保持关闭；没有从聊天、旧版台账或其他资料自动复制密钥。所有本次收费调用测试使用合成响应，外部付费请求为零。

## 2. 已落地行为

- 严格 TypeScript 契约、设置版本冲突检查、默认关闭。建议时间 07:00、Australia/Sydney；可自行修改开始时间、时区、提醒时间和三种额度。
- 保存/刷新/打开页面不启动采集。勾选费用说明后，才能手动检查或启用后续定时；首次启用从未来档位开始，不补刷以前的付费请求。
- 后端每 60 秒检查到期。进程内串行与 SQLite 日键共同阻止重复执行。离线多天只选最近已到期且不超过 24 小时的一次，不重放整个历史。
- Sydney 夏令时：不存在的 02:30 顺延到当日下一个有效分钟；秋季重复时间取首次。提醒窗口开始后保持原窗口结束点，修改时区不重置当日名额。
- DeepSeek **官方** Anthropic-compatible Messages + `web_search_20250305` 搜索，单请求 `max_uses=1`；只接受原生 `web_search_tool_result`。模型正文里的 URL 不当作搜索证据；发布时间一律保留未知，除非后续原文核实。
- 搜索近 24 小时、7 天、30 天；已发现至少 5 条新线索时不再扩大。当前每天轮换 3 家台账公司作为重点查询，**不是覆盖所有公司**。
- 只抓已有审阅来源注册表中的精确 URL（当前 3 个，2 个仅招聘入口）。新搜索 URL 只作为线索；不自动扩大网络访问范围、不伪称通过岗位核验。
- 三种持久化 UTC 日额度：搜索最多 6 请求、页面最多 20 请求、提取最多 6 请求；用户可调低。本轮实际最多 3 次搜索、3 次已登记来源复核。手动岗位检查共享网页/提取额度；robots 和重定向也计数。超时、未知费用不退回额度，不盲重试。
- 模型配置或匹配条件版本变化，暂停自动执行，要求重新核对。进程中断的运行记录为 interrupted，未知请求保留，不自动重发。
- 日报、原始搜索链接、错误、阶段、调用计数保存在 catalog.db；结束状态和报告在同一事务提交。新线索、条件初筛通过、待核对、内推线索分开计数，自动入库数为 0。
- 一次性提醒由 SQLite 事务领取，非 localStorage。两窗口只有一个领取成功。关闭提醒不删除日报；「稍后看」不标已读。已领取但浏览器崩溃可能没展示，保留未读入口，不保证 exactly-once 可见。
- 沿用薄荷石墨和现有角色资产。非模态来信不抢焦点、不播放声音、不定时消失；输入框编辑、隐藏页、可见模态或全屏时延后领取；窄屏为行内卡片。支持日报详情与历史分页。

## 4. 正常、边界、异常验证

| 类型 | 已执行验证 | 证据 |
|---|---|---|
| 正常 | 保存不付费；手动搜索→报告；按时无浏览器执行；第二天可继续；启用未来档位 | daily-api / daily-service / 浏览器 |
| 时间边界 | Sydney 春进秋退、闰日、跨 UTC 日、跨年、时区修改、长时间离线最近一次补查 | daily-clock / daily-store |
| 并发/幂等 | 同一日多次 tick；重复手动 ID；启用回执重放；两个窗口同时领取 | daily-store / daily-service / 浏览器 |
| 预算 | 达到上限拒绝派发、重开不清零、未知费用不退款、请求状态不可倒退 | daily-store |
| 外部失败 | 429、401、重定向拒绝、取消、非法/无真实结果块、过大结果、私网 URL、密钥回显 | search-deepseek / 既有 model/source 测试 |
| 存储失败 | 插入日报/通知时 SQLite 注入写失败，事务回滚；停止新请求；恢复为 interrupted | daily-store / daily-service |
| 安全 | token/profile/Origin 隔离、严格字段/分页上限、XSS 安全文本渲染、DNS 公网及来源精确 URL 限制 | daily-api / 既有 source/model 测试 |
| UI | 1440 桌面、390 窄屏、暗色、设置重载、日报查看、暂停、跨模块、跨窗口一次、刷新不重弹、无 JS 错误 | verify-daily.mjs |
| 数据 | v3 迁移备份、物理关闭再打开；实际本机升级前后逻辑摘要相同，4 个库完整性 ok | daily-migration / inspect-profile.mjs |

本次发现并修复：

1. 离线超过一天只跳过旧 nextDue，导致漏掉最近应执行档位；改为求最近本地档位并仅补一次。
2. 启用重放缺持久回执；增加激活回执，停用之后旧请求不会把功能重新开启。
3. 快速任务结束时并发读取状态/日报得到不一致快照，UI 最多晚 30 秒才显示；改为先读取状态再读取日报，浏览器要求 5 秒内看到合成结果。
4. 编辑期间后台刷新会抬高保存版本；保存改为使用开始编辑时的 revision，保留冲突检查。
5. 历史分页刷新会丢掉已展开的旧页；合并新报告并按 id 去重，不删除已加载记录。
