# 阶段 3 评测报告与复现入口

日期：2026-09-20。结论：手动采集工程版可在隔离资料中使用；不等于全网搜岗、真实模型质量达标或每日自动更新已上线。

## 1. 已交付路径

「岗位更新」→ 选择登记来源 → 可选只读检查 / 有限模型提取 → 查看运行与逐字段原文 → 勾选候选 → 内联确认 → 已收录岗位。

- 不自动把候选写入台账，不修改个人已投状态。公司信息经过维护者登记才允许在末尾追加；既有公司行不覆写。
- 未配置模型、未确认偏好时仍能检查网页；提取必须有当前配置、本人确认偏好及页面上的费用告知勾选。
- 每次 1–3 来源、最多 3 次模型尝试、20 次 HTTP 请求、5 分钟；不自动重试。窗口关闭不取消后台任务；运行中可显式取消，进程中断不会补跑。
- 未披露字段为 null。证据必须逐字出现在快照中；标题/URL/公司不能由模型任意改写。入库再次核对哈希、引文范围及来源，超过 24 小时必须重查。
- 新增/变化/重复/需人工审核分开，重复候选不可再次收录。结果分页 100 条；记录最多保留 1000 次后停止新增，不静默删除。

## 2. 评测口径

固定集 `tests/fixtures/jobs_gold.json`，版本 `synthetic-v1`，SHA-256：

`2bb2cdf579e9aefb8b438fbb766c485a3b4567dd2956d0e9178c09df75e91ac9`

60 条均为合成工程用例：20 匹配、10 不匹配、10 不确定、8 身份去重、6 开放状态、6 恶意响应。40 dev / 20 reserve；reserve 同样由实现者编写并已执行，不是独立盲测。

`npm run eval:jobs` 只度量其中 40 条带 eligibility 标签的规则判断，不调用模型：

| 分组 | 分类样本数 | TP / FP / FN | Precision / Recall / F1 | unknown |
|---|---:|---|---|---|
| dev | 27 | 14 / 0 / 0 | 1.00 / 1.00 / 1.00 | 7/27，25.93% |
| reserve | 13 | 6 / 0 / 0 | 1.00 / 1.00 / 1.00 | 3/13，23.08% |

其余 20 条由 `npm test` 验证身份、开放性、安全行为。以上数值只说明这些明确构造的输入通过，不代表真实模型或全网招聘数据 100% 准确。真实字段提取精确率、两轮稳定性、token 成本均未取得测量结果。

## 3. 验收与限制

- TypeScript 全量测试、构建与 Python 旧版回归：最终计数见 [实现与测试记录](阶段3-实现与测试记录.md)。
- 合成 HTTP 端到端：鉴权、跨资料拒绝、保存偏好、模型请求、候选预览、显式接纳、重试回执、个人状态不变。
- 浏览器使用独立假提供者：3 来源中 2 候选、1 robots 拒绝；分别显示条件初筛通过/待核验，勾选收录、刷新重开成功；正文中的 `<script>` 按文本显示。无真实模型调用和费用。
- 实际网页只读：速境岗位详情、MiniMax 招聘入口、Kimi 校招入口。入口页不能冒充单岗位；Kimi 静态内容不足时显示 dynamic。适配范围仅这 3 个登记入口，不宣称覆盖 315 家公司的职位。
- 320 / 768 / 1024 / 1440 CSS 像素均无横向溢出；查看亮/暗主题，控制台未见 JS 错误。原生悬浮助手不是此次浏览器验收范围。
- SQL 中途异常已测试事务回滚；写入故障是可控注入，不等于真实磁盘损坏/物理断电测试。独立进程断电式中止接纳、三家公司真实模型流程、另一台电脑未验收。
- 身份目前由「已登记 sourceId + 规范化 URL」确定；公司多个来源的跨站同岗合并还需各官方岗位 ID 适配，不宣称通用跨站自动去重。
- 仅静态 HTML；不执行网页 JS，不读取登录接口，不绕过验证码。完整正文超过 16000 字符会拒绝，而非截掉可能重要的门槛。
- 规则属于保守初筛，复杂学历/专业/海外毕业窗口须人工复核。公开网页显示可申请不代表实际投递成功。

## 4. 独立预览与运行

本轮入口：<http://127.0.0.1:18770/>，数据目录：

`%USERPROFILE%\AppData\Local\XiaozhaoGaogaoshou\profiles\stage3-preview-20260920`

它有同一份公开公司种子，但不复制你的已投记录或模型密钥。不要将预览中的「未投」误解成旧台账记录丢失。原桌面入口及 18763/18765 未切换。

在项目目录手动重开：

```powershell
npm run build
node dist/server/server/main.js --port 18770 --data-dir '%USERPROFILE%\AppData\Local\XiaozhaoGaogaoshou\profiles\stage3-preview-20260920'
```

目录 schema 升到 v2 前在当前资料的 backups 生成一致性 v1 快照。旧二进制不保证能打开 v2；回退必须先停新实例，保留当前目录副本，再使用升级前快照，不能直接覆盖仍运行的数据库。
