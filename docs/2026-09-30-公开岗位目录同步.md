## 可重复同步

运行：

```powershell
python -X utf8 scripts/sync-public-catalog.py `
  --db <catalog.db> `
  --additions src/shared/catalog-additions.ts `
  --metadata src/shared/catalog-metadata.ts
```

脚本会先执行 SQLite `integrity_check`，仅追加源码中尚不存在的公司，并同步首次发现日期及企业性质覆盖；检测到姓名、手机号、个人邮箱或详细住址时会拒绝写入。
