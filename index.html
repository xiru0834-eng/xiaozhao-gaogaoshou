使用说明、内推注意事项与数据存储

这张表怎么用

  • 分组默认按截止排。近期截止在前，已过期在末尾且默认折叠；用「分组」下拉选择行业、性质或不分组。目录日期仅作提醒，投前请核对官网。
  • 点码即复制。点推荐码按钮即复制；点击公司名或「核验说明」查看备用码、失效说明和原始备注。标了「26 届」「实习」的不用于当年校招。
  • 入口链接指向公司官方系统或带推荐参数的深链；只给了公众号/邮箱的，「搜入口」按钮直接搜当年入口。

状态存在哪里

  • 按 README 启动「校招高高手」。投递状态保存在当前应用目录的 qiuzhao.db，不上传 GitHub。等待右上角显示「已写入 qiuzhao.db」后即可关闭。
  • 关闭重开、电脑重启或清浏览器缓存，不会删除已保存的数据库状态。请保留应用目录；原来的临时 HTML 是独立旧版本，其浏览器进度不会自动迁移。
  • 备份：启动时按日备份到 backups，也可点击「备份数据库」下载副本。数据库记录公司名、投递状态和更新时间；公司目录保存在应用 HTML 中。

几个真会踩的坑

  • 投递前必须先填码的：沐瞳（投后补不了）、小红书（提交后不能补码）、京东方（只能首次网申填）、招银网络科技（先打开绑码链接再去官网网申，顺序反了码就丢）。
  • 志愿数硬限制：大华、去哪儿、携程、农银金科、中证股转、网易系各 1 岗；小红书 5 志愿可排序；阿里云一次投递 2 个意向且提交不可改；搜狐、泡泡玛特、建信金科 2 岗；赛力斯、汇川 3 志愿；名创优品不限。
  • 官方明确不设内推的：华为、工行、农行、建行、中行、邮储、中国移动、中国电信、联通、中国中车、申万宏源。这些公司出现的"付费内推"都是假的，直投就行。
  • 学历及毕业时间：按本人真实资料填写；海外学历认证要求以各单位当期公告为准。
  • 邮箱直投：以官方要求为准，例如 应聘-岗位名-本人学校-毕业届别，附件 姓名-简历.pdf。

这是 2026-09-20 整理的共享目录快照，线索来自公司官网、高校就业网及公开招聘社区，不能保证全部岗位仍开放。公开推荐码未逐一实测，也不保证有效；使用前核实公司、批次和适用岗位，不为内推付费。投递记录仅保存在本人电脑。
